Under the hood · 02
Architecture

Native control, web-scale reach.

R
Application core

Rust native runtime

Owns startup, application state, window lifecycle, IPC, persistence, downloads, updates, and async services.

Desktop shell

Tao event loop

Native Windows events and frameless window control.

Browser bridge

Wry + WebView2

Chromium-compatible content through layered child WebViews.

Interface layer

Custom chrome WebView

Toolbar, workspaces, overlays, new tab, downloads, settings, and AI.

Content layer

Per-tab WebViews

Shared profile for cookies, local storage, cache, and native browser behavior.

Local + connected services

SQLite · Keychain · AI APIs

Local user data, protected credentials, and multi-provider intelligence.

Ventus
Core capabilities · 03
What I built

A complete browser experience.

01

Native browser shell

Custom frameless Windows UI with layered WebViews, Win32 clipping, z-order, and responsive layout control.

02

Workspaces and tabs

Tab search, pinned tabs, workspace navigation, quick links, bookmarks, history, and downloads.

03

Multi-provider AI

An integrated assistant supporting OpenAI, OpenRouter, Anthropic, and local Ollama models.

04

Local-first storage

SQLite persistence for browser data with API secrets kept outside the database in the Windows keychain.

05

Privacy controls

Built-in ad blocking, tracking URL cleanup, site permissions, secure DNS options, and local settings.

06

Desktop-grade delivery

Downloads, native file actions, automatic updates, Windows installers, and release build tooling.
