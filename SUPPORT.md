# Support

Ventus is an early open-source desktop browser. Support is community-driven.

## Getting Help

Use GitHub Issues for:

- Reproducible bugs
- Broken builds
- Crashes
- Download, history, bookmark, or navigation problems
- Feature requests
- Documentation problems

Before opening an issue:

- Search existing issues.
- Try the latest main branch or latest release.
- Include your Windows version.
- Include the app version or commit.
- Include exact steps to reproduce.
- Add screenshots or screen recordings for UI bugs.

## Not For Support

Do not share:

- API keys
- Local database files with private browsing history
- Personal downloaded files
- Private URLs
- Secrets from `.env` or other local config files

## Development Questions

For code questions, include the file or module you are working on and what behavior you expected.
