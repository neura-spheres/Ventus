Ventus 1.0.39 brings Developer Tools into the browser, fixes the YouTube fullscreen resize issue, and refreshes the adblocker and app dependencies.

### Developer Tools, right inside Ventus

You can now inspect a page without juggling another window. DevTools opens in a resizable panel at the bottom of the browser, with Elements, Console, Network, Sources, and the other tools provided by Microsoft's DevTools frontend.

- Right-click something on a page and choose **Inspect** to jump straight to its HTML tag.
- Press **F12** or **Ctrl+Shift+I** to open or close the panel.
- Use **Ctrl+Shift+C** or **Select element** to pick something on the page.
- Drag the divider to give the page or DevTools more space.

The panel follows the active tab and fills its available width. Fullscreen temporarily hides it, then brings it back when you leave fullscreen.

### Fixes and updates

- Fixed an issue where dragging the bottom-right corner during YouTube fullscreen could resize the browser window.
- Updated the bundled **uBlock Origin Lite to 2026.1026.1812**, including its filter rules and scripts.
- Fixed extension refresh order so the updated adblocker loads when the browser starts.
- Updated compatible Rust dependencies, including networking, database, PDF, and ZIP libraries.
- Corrected the installer's WebView2 detection so it recognizes an existing runtime properly.

### Downloads

- **Ventus-Setup-1.0.39.exe**: recommended for installing or updating Ventus.
- **Ventus-1.0.39-windows-x64.zip**: extract the whole folder and run `ventus.exe`. Keep the included `assets` folder beside it. This uses the normal Ventus profile; it does not create a separate portable profile.
- **ventus.exe**: the standalone application binary for an existing installation with its assets already present.
- **SHA256SUMS.txt**: checksums for the downloads.

Windows 10 build 17763 or later is required. Setup includes Microsoft's WebView2 bootstrapper, which downloads the runtime if needed. DevTools also needs internet access for its first frontend load.

The app's Firebase and Cloudinary configuration is included in the Windows build, so you do not need to supply a separate `cloud.env` file. Personal AI provider keys are still added through the app's settings.

These locally built downloads are unsigned, so Windows may show a publisher or SmartScreen warning. The source repository has not been updated for this release; GitHub's automatic source archives do not contain the local changes used to build these binaries.
