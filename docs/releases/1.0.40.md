Ventus 1.0.40 focuses on fixing the first-page adblock startup issue and making Copy image work properly on Twitter/X. There’s also a small menu cleanup.

### What’s fixed

- **Adblock startup:** the first protected page now waits for uBlock Origin Lite to finish loading its rules and page scripts. Previously, a page could start loading before the blocker was ready, which could let an ad through on the first YouTube video.
- **Old adblock scripts:** Ventus refreshes the unpacked extension when initializing it, so script registrations from the previous bundle don’t stick around after an update. Normal and private profiles have separate readiness checks.
- **Copy image:** fixed Windows clipboard ownership when copying images. The same fix also covers native text copying and cleans up memory if a clipboard write fails.
- **Twitter/X images:** public images from another domain now use an anonymous request first. Same-origin images keep their session cookies, and protected external images can retry with credentials.
- **Cleaner menus:** removed the extra Developer tools entry from the main menu and the right-click menu. **Inspect** is still there, and **F12**, **Ctrl+Shift+I**, and **Ctrl+Shift+C** still work.

### Downloads

- **Ventus-Setup-1.0.40.exe**: recommended for installing or updating Ventus. Fully close the browser before installing.
- **Ventus-1.0.40-windows-x64.zip**: extract the whole folder and run `ventus.exe`. Keep the included `assets` folder beside it. This uses the normal Ventus profile, not a separate portable profile.
- **ventus.exe**: application binary for an existing installation that already has its assets.
- **SHA256SUMS.txt**: checksums for the downloads.

The app’s Firebase and Cloudinary configuration is included in the Windows build. No separate `cloud.env` file is needed. Personal AI provider keys are still added through settings.

### A few things to know

Windows 10 build 17763 or later is required. Setup includes Microsoft’s WebView2 bootstrapper, which downloads the runtime if needed. DevTools needs internet access for its first frontend load.

The first page may wait a few seconds while the adblocker starts. If initialization fails or times out, Ventus shows a warning and loads the page rather than leaving it blank. YouTube changes its ads regularly, so this fixes the startup race without promising that every ad format will always be blocked.

These local builds are unsigned, so Windows may show a publisher or SmartScreen warning. The fixes were built from the local working tree without pushing repository changes; GitHub’s automatic source archives do not contain all the changes used to build these downloads.
