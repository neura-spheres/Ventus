Ventus 1.0.43 is a small update that makes tab muting actually work. Everything from 1.0.42 is included, along with the fix from the v1.0.43-pre26112701 prerelease.

### What's fixed

- **Tab muting:** muting a tab now uses WebView2's own tab mute. Before, Ventus only muted the page's `<audio>` and `<video>` elements, so sound from Web Audio, embedded frames, and players created after muting could still get through.
- **Mute stays on:** a muted tab stays muted when you go to another page in the same tab, and when a sleeping or rebuilt tab wakes back up. Before, navigating reset it.
- **Mute icon:** the tab's mute icon only changes when the mute is actually applied.

### Downloads

- **Ventus-Setup-1.0.43.exe**: recommended for installing or updating Ventus. Fully close the browser before installing.
- **Ventus-1.0.43-windows-x64.zip**: extract the whole folder and run `ventus.exe`. Keep the included `assets` folder beside it. This uses the normal Ventus profile, not a separate portable profile.
- **ventus.exe**: application binary for an existing installation that already has its assets.
- **SHA256SUMS.txt**: checksums for the downloads.

The app's Firebase and Cloudinary configuration is included in the Windows build. No separate `cloud.env` file is needed. Personal AI provider keys are still added through settings.

### A few things to know

Windows 10 build 17763 or later is required. Setup includes Microsoft's WebView2 bootstrapper, which downloads the runtime if needed. DevTools needs internet access for its first frontend load.

These builds are unsigned, so Windows may show a publisher or SmartScreen warning.
