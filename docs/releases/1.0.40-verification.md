# Ventus 1.0.40 verification

Release preparation date: 2026-10-30. Publication targets the existing remote commit `1e36fdd7e6ad0bf8a58383883ae9613e2671fc5e`; no source commits or branch pushes are part of this release. The built working tree includes the adblock startup, clipboard, Twitter media-fetch, and menu fixes described in the release notes.

## Checks

- `cargo fmt --check`, `cargo check --locked`, and `git diff --check` passed.
- 148 regular Rust tests passed. The clipboard test is ignored in the normal suite because it changes the desktop clipboard temporarily.
- The clipboard test passed separately using the current 1.0.40 test executable. It checks cross-thread Windows ownership, DIB dimensions/pixels, PNG contents, text, and a real Twitter CDN JPEG. Clipboard contents were backed up in memory and restored afterward.
- All 23 JavaScript tests passed, covering menu dispatch, media-fetch credentials, startup readiness, DevTools transport/shortcuts, and fullscreen resize suppression.
- Chrome inline script syntax passed. Both Developer tools menu entries are absent; Inspect remains.
- All 270 adblocker JSON files parsed. The bundled uBOL version is 2026.1026.1812.
- The 1.0.40 release build output emits all six nonempty cloud settings, matching the local environment file exactly. Values were not printed in verification output.
- Firebase project configuration returned HTTP 200 and authorized the expected auth domain. Cloudinary recognized the configured upload preset, while an invalid-preset control failed. These checks did not create an account or upload an asset.
- RustSec audit with `--no-yanked` reported zero known vulnerabilities, eight maintenance warnings, and two soundness warnings across the full dependency graph. Target-specific details remain in the dependency refresh report.
- The bundled WebView2 bootstrapper has a valid Microsoft signature.
- `cargo build --release --locked` and Inno Setup compilation passed. The app and installer report version 1.0.40.
- The optimized release startup log reported version 1.0.40, readiness true, Optimal filtering, six enabled rulesets, and the current main-world scriptlets. The first queued navigation began after readiness.
- ZIP integrity passed. Its executable matches the release build, all 928 adblocker files match the bundle byte for byte, both requested menu entries are absent from the compiled executable, and Inspect remains. No raw environment files or private key files were packaged.

## Publication

Published [Ventus v1.0.40](https://github.com/neura-spheres/Ventus/releases/tag/v1.0.40) as the latest stable release. All four uploaded files matched their local SHA-256 digests and byte counts before publication, and release notes matched the local notes file. Both the remote main branch and local HEAD remained at `1e36fdd7e6ad0bf8a58383883ae9613e2671fc5e`. No source commits or branch pushes were performed. The release app was left running normally, without a remote-debugging listener.

## Limits

The app and installer are unsigned. Clean-machine Windows installation, actual account sign-in/sync, a complete Cloudinary upload, and paid AI calls were not exercised. Earlier automatic approval review blocked remote-debugging and URL-driven browser test launches; normal startup logs and native clipboard tests are used instead. The originally reported Twitter image URL was not supplied, and YouTube ad playback varies by account/server response, so manual checks of those exact cases remain useful. These checks do not establish that every site or future ad format will work without problems.

Developer Tools downloads its frontend assets on first load. The ZIP uses the ordinary Ventus profile and is not an isolated portable profile. Raw environment files and personal API keys must not be included in the downloads.
