Ventus 1.0.41 fixes downloads that got stuck, adds a Keep or Discard prompt for risky files, and makes the adblocker more reliable when you allow ads on a site or turn it off and on.

### What’s fixed

- **Stuck downloads:** `.exe`, `.jar`, `.msi`, `.bat` and similar files no longer sit at 0%. WebView2 was waiting for an answer to a prompt that Ventus hides.
- **Downloads that open a new tab:** Ventus no longer treats the download as a failed page and loads it again. Tabs opened only for a download close themselves, and closing a tab no longer stops its download.
- **Big files:** the fast downloader was rewritten. It gives up on silent servers instead of waiting forever, uses fewer connections when a host limits them, resumes dropped ones, and checks that each piece is the right one. Cancel also works while it is waiting.
- **Adblock reloads:** a failed adblocker start no longer keeps stopping and reloading your page. Switching back from a site where you allow ads doesn’t reload your tab either, so text you typed stays there.
- **Allowing ads on a site:** the exception now applies to that site only. Before, it could turn the blocker off for every tab, or do nothing at all.
- **Turning the adblocker off and on:** it restarts properly instead of hanging for 15 seconds and loading pages unfiltered. The current tab reloads so the change applies.
- **Closing Ventus:** fixed the process staying alive in the background after you closed the window with only a new tab page open.

### What’s new

- **Keep or Discard:** file types that can run code now stop at **Could be harmful** when they finish. **Keep** saves the file and **Discard** deletes it. Files waiting for an answer stay at the top of the downloads panel and are still there after a restart.
- **Download again:** failed downloads have a button to retry them.
- **uBlock Origin Lite:** updated to **2026.1122.1948**, including its filter rules and scripts.

### Downloads

- **Ventus-Setup-1.0.41.exe**: recommended for installing or updating Ventus. Fully close the browser before installing.
- **Ventus-1.0.41-windows-x64.zip**: extract the whole folder and run `ventus.exe`. Keep the included `assets` folder beside it. This uses the normal Ventus profile, not a separate portable profile.
- **ventus.exe**: application binary for an existing installation that already has its assets.
- **SHA256SUMS.txt**: checksums for the downloads.

The app’s Firebase and Cloudinary configuration is included in the Windows build. No separate `cloud.env` file is needed. Personal AI provider keys are still added through settings.

### A few things to know

Windows 10 build 17763 or later is required. Setup includes Microsoft’s WebView2 bootstrapper, which downloads the runtime if needed. DevTools needs internet access for its first frontend load.

Microsoft SmartScreen is switched back on inside the browser engine, because turning it off was part of what froze downloads. It can send URLs to Microsoft. Clear all in the downloads list also deletes files you haven’t chosen to keep.

The first page may wait a few seconds while the adblocker starts. If it fails to start, pages load without it and Ventus retries in the background. YouTube changes its ads regularly, so there is no promise that every ad format will always be blocked.

These local builds are unsigned, so Windows may show a publisher or SmartScreen warning. The fixes were built from the local working tree without pushing repository changes; GitHub’s automatic source archives do not contain all the changes used to build these downloads.
